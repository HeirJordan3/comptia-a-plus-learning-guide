## What Is It?

A laptop packs a full computing platform into a portable, battery-powered system.

That compact design is powerful, but it creates a trade-off. Laptop parts are built to precise specifications, so troubleshooting and replacement often require more care than desktop work.

Some laptops are designed to be opened and upgraded. Others make internal access difficult. Always follow the manufacturer’s process for that specific model.

## Why Does It Matter?

Help desk technicians constantly support laptop hardware issues:

- Battery will not hold a charge
- Keyboard keys fail
- Storage is slow or failing
- User wants an SSD upgrade
- Wireless or Bluetooth stops working
- Camera or microphone fails in meetings
- User wants biometric login

Understanding laptop hardware helps you decide what can be replaced, what needs a technician teardown, and what is model-specific.

## Real-World Analogy

Think of a laptop like a suitcase that also works as an office.

Everything is packed tightly so it can travel. That is convenient, but if one item breaks, you may need to carefully unpack several layers just to reach it. Some suitcases open easily. Others are almost sealed shut.

## How It Works

### Batteries

Laptop batteries are not all the same.

Two common battery technologies are:

- Lithium-ion
- Lithium-ion polymer

Both are designed to avoid the older “memory effect.” That means you can recharge them when convenient without the same capacity concerns older battery types had.

Battery form factors are model-specific. A battery from a different make or model usually will not fit.

#### Modular vs Built-In Batteries

| Battery Style | What It Means |
| --- | --- |
| Modular | User can often remove and replace the battery easily |
| Built-in | Battery is inside the system and usually needs a technician teardown |

Modular batteries may use a release button so one battery pops out and another slides in. Built-in batteries usually cannot be swapped by the end user.

### Keyboards

Keyboards are one of the most-used laptop parts, so they are commonly replaced.

On many laptops, keyboard replacement is fairly straightforward:

1. Remove a bezel or a few screws
2. Lift out the keyboard as a unit
3. Disconnect the ribbon cable from the system board
4. Connect and install the replacement

#### Quick Keyboard Troubleshooting Tip

If a laptop keyboard is failing, plug in an external USB keyboard.

That helps you:

- Keep working around the problem
- Decide whether the issue is the laptop keyboard hardware or something in the OS

Laptop keyboards are compact. They often include:

- Function keys for secondary features
- Windows keys on Windows systems
- A numeric keypad on wider models

### Keycaps

Sometimes the whole keyboard is fine, and only one key or keycap is damaged.

Desktop keycaps are usually more robust. Laptop keycaps are fragile. Follow manufacturer instructions carefully so you do not damage the mechanism underneath.

### Laptop Memory — SO-DIMM

Laptop memory often uses a smaller module called a **SO-DIMM**.

SO-DIMM stands for Small Outline Dual In-line Memory Module.

| Memory Style | What It Means |
| --- | --- |
| SO-DIMM | Modular memory that can often be replaced |
| Soldered memory | Memory is fixed to the board and not user-upgradable |

On modular systems, there is often a panel on the underside of the laptop. You can remove or add SO-DIMM modules, then press them into place until the clips lock.

If memory is soldered, upgrading usually means replacing the system board.

### Storage — HDD to SSD

Older laptops often used spinning hard drives. Laptops commonly used a **2.5-inch** hard drive form factor, smaller than many desktop 3.5-inch drives.

Modern laptops usually use an **SSD**, or Solid State Drive.

SSD advantages:

- Faster performance
- No moving parts
- Better reliability for portable devices

#### 2.5-Inch vs M.2

| Drive Type | Notes |
| --- | --- |
| 2.5-inch SSD/HDD | Older common laptop form factor; separate data and power connections |
| M.2 SSD | Smaller modern form factor; plugs into an M.2 slot |

M.2 installation is often simple:

1. Slide the M.2 drive into the slot
2. Press it down
3. Secure it with a screw

2.5-inch replacement usually involves removing a few screws and sliding the drive out of its bay or connector.

### Imaging / Cloning an Upgrade

Many users upgrade an old spinning drive to an SSD.

Options include:

- Fresh OS install on the SSD, then manually move files and reinstall apps
- Imaging or cloning software to copy the old drive to the new SSD

Imaging/cloning is often faster for a full move. Many SSD manufacturers include imaging software. Third-party tools can also copy a drive or partition.

Common approaches:

- Create an image on separate storage, install the new drive, then restore
- Connect both old and new drives and clone directly from one to the other

### Wireless Cards and Antennas

Many modern laptops have no wired Ethernet port and rely on wireless connectivity such as 802.11 Wi-Fi or Bluetooth.

Wireless features may be:

- Built into the motherboard
- Provided by a modular mini PCI or mini PCIe card on older systems

Bluetooth is often used as a short-range **PAN**, or Personal Area Network, for devices such as mice and keyboards.

Modular wireless cards often include small antenna connectors. Antenna wires commonly run up around the display so they sit higher when the lid is open.

You may see:

- Main antenna connector
- Auxiliary antenna connector
- A separate Bluetooth antenna connection

If you replace a laptop screen, watch for antenna wires coming from the display assembly.

### Biometrics

Many modern operating systems support biometric login instead of only a password.

Common options:

- Fingerprint recognition
- Face recognition

You need both:

- An OS that supports biometrics
- Hardware such as a fingerprint reader or a suitable camera

In Windows, examples include:

- Windows Hello Face
- Windows Hello Fingerprint

### NFC

NFC stands for Near Field Communication.

NFC is very short-range wireless communication, often about **4 centimeters or less**.

Common uses:

- Phone or smartwatch payments at a point-of-sale terminal
- Quick authentication with an access card or NFC device
- Warehouse, manufacturing, shipping, hospital, and similar workflows

### Cameras and Microphones

Most laptops include a camera near the top center of the display.

Uses include:

- Saving video to a file
- Video conference calls

Many laptops also include built-in microphones near the camera so audio and video work together.

Built-in cameras are convenient. If a user needs higher quality or more features, an external webcam can be attached.

## Common Mix-Ups

### Modular Battery vs Built-In Battery

- Modular = usually user-replaceable
- Built-in = usually technician teardown

### HDD vs SSD

- HDD = spinning platters
- SSD = solid-state memory, faster and more reliable for laptops

### 2.5-Inch vs M.2

- 2.5-inch = larger older form factor
- M.2 = smaller modern board-mounted style

### SO-DIMM vs Soldered Memory

- SO-DIMM can often be upgraded
- Soldered memory usually cannot

### NFC vs Bluetooth

- NFC = very short range, often used for taps and quick auth
- Bluetooth = short-range personal accessories and peripherals
