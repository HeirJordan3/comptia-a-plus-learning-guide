## What Is DNS?

DNS stands for Domain Name System.

Humans remember names. Networks use addresses.

DNS provides **name resolution**. It translates a hostname people can remember into an IP address a computer can use.

```text
www.example.com
        ↓
       DNS
        ↓
   IP Address
        ↓
     Server
```

### Real-World Analogy

Think about the contacts list on your phone.

You remember “Mom” instead of memorizing a long phone number. Your phone looks up the name and finds the number.

DNS works in a similar way. A hostname such as `www.example.com` is easier to remember than an IP address. DNS finds the address for you.

## Why Does It Matter?

DNS shows up constantly in IT support.

### Help Desk Scenario

A user cannot reach `server.company.com`, but the server works when accessed using its IP address.

That pattern is important:

- IP works
- Hostname does not work

That usually points to a DNS or name resolution problem.

If users can browse by IP but not by name, start investigating DNS.

## How It Works

### DNS Is Distributed and Hierarchical

DNS is **distributed**, meaning no single server stores every hostname on the internet. Responsibility is shared across many systems.

DNS is **hierarchical**, meaning names are organized in layers, like folders inside folders.

```text
ROOT
 |
.com
 |
example
 |
www / mail
```

Common top-level domains include:

- `.com`
- `.org`
- `.net`
- `.us`
- `.ca`
- `.uk`

You do not need deep DNS infrastructure knowledge for A+. Focus on what DNS does and which records matter in support and exam scenarios.

## DNS Resource Records

DNS stores information in **resource records**.

| Record | Purpose |
| --- | --- |
| A | IPv4 address |
| AAAA | IPv6 address |
| CNAME | Alias |
| MX | Mail exchanger |
| TXT | Text information |

### A Record

An **A** record points a hostname to an IPv4 address.

Memory tip: A → IPv4

### AAAA Record

An **AAAA** record points a hostname to an IPv6 address.

Memory tip: AAAA → IPv6

Compare them clearly:

- A = IPv4
- AAAA = IPv6

### CNAME

A **CNAME** record creates an alias.

It points one hostname to another canonical hostname.

Analogy: Robert and Bobby. Both names can refer to the same person. Bobby is a nickname that still points back to Robert.

In DNS, a CNAME is an alias that points to another hostname, not directly to an IP address.

### MX

An **MX** record identifies the mail exchanger for a domain.

Memory tip: M = Mail

When email is sent to a domain, MX records help receiving systems know which mail servers should accept that mail.

### TXT

A **TXT** record stores text information in DNS.

Examples include:

- Domain verification
- Email-related configuration
- Other published text information

Important: TXT is not exclusively an email record. It can store many kinds of text values.

## TTL

TTL stands for Time to Live.

TTL tells systems how long DNS information can remain cached before it should be requested again.

### Directions Analogy

If someone just told you where the cafeteria is, you do not ask again 30 seconds later. You remember the directions for a while.

TTL works like that for DNS answers. It controls how long the answer can be reused from cache.

Memory tip: TTL → Cache duration

## SPF, DKIM, and DMARC

These technologies often appear with email authentication and DNS.

| Technology | Think |
| --- | --- |
| SPF | Authorized sending servers |
| DKIM | Digital signature |
| DMARC | Policy + reporting |

### SPF

SPF asks: Who is authorized to send?

It helps identify which servers are allowed to send email for a domain.

### DKIM

DKIM asks: Can the signature be verified?

It helps verify that a message has a valid digital signature tied to the domain.

### DMARC

DMARC asks: What should happen when authentication fails?

It provides policy and reporting guidance for receiving mail systems.

## Common Mix-Ups

### A vs AAAA

- A = IPv4
- AAAA = IPv6

### CNAME vs A

- A points to an IPv4 address
- CNAME points to another hostname (an alias)

### SPF vs DKIM vs DMARC

- SPF = authorized senders
- DKIM = digital signature
- DMARC = policy and reporting

### TXT Is Broader Than Email

TXT can be used for email-related settings, but it is not only for email.
