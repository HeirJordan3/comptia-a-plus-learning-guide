# Network Tools

By the end of this lesson, you should understand:

- What a cable crimper is used for
- What a Wi-Fi analyzer and spectrum analyzer show

- What a punch-down tool does

- What a network tap and SPAN / port mirror do

## What Is It?

Network technicians keep a set of physical tools for installing, testing, and troubleshooting cables and wireless links.

This lesson covers:

- Crimpers
- Wi-Fi analyzers
- Tone generators
- Punch-down tools
- Cable testers
- Loopback plugs
- Network taps / port mirroring

## Why Does It Matter?

Help desk and field technicians use these tools when:

- A custom Ethernet cable needs an RJ45 connector
- Wi-Fi is slow or crowded
- Someone cannot find the other end of a cable in a closet
- Wires must be terminated on a punch-down block
- A new cable might be wired wrong
- A NIC or interface may be bad
- Packets need to be captured from a live link

## Real-World Analogy

Think of network tools like a mechanic’s kit:

- Crimper = attaches the connector permanently
- Tester = checks that wires are connected correctly
- Tone generator = finds which wire is which in a big bundle
- Analyzer = listens to the wireless “air traffic”
- Tap / SPAN = makes a copy of traffic for inspection

## How It Works

### Cable Crimper

A **crimper** permanently attaches a connector to a cable.

Common use: crimping an **RJ45** connector onto twisted-pair Ethernet cable.

For copper connectors, the crimp pushes metal contacts through the wire insulation so they touch the copper inside. It also presses a cable stay so the jacket is held firmly and the connector will not pull off easily.

Useful extras for making cables:

- Electrician scissors or cable snips
- Wire stripper

With practice, you can make custom-length patch cables yourself. The same idea applies to other media too, such as coax or fiber, with the right connectors and tools.

### Wi-Fi Analyzer

A **Wi-Fi analyzer** helps you evaluate wireless network health.

It can show:

- Channels / frequencies in use
- Signal strength from your access point
- Nearby networks
- Interference signs
- Devices communicating with an AP

If you are far from the AP, noise may be close to the useful signal and throughput suffers. Closer to the AP, signal strength usually improves and the analyzer makes that visible.

A **spectrum analyzer** goes deeper by showing more of the radio spectrum, including non-802.11 sources that can cause interference.

### Tone Generator and Inductive Probe

A **tone generator** helps find both ends of a cable in a large wiring closet.

It is really two parts:

1. Tone generator — puts an analog tone onto the cable
2. Inductive probe — listens for that tone without needing to touch bare copper

Workflow:

1. Connect the tone generator to one end of the cable
2. Move the inductive probe across cables in the closet
3. When the probe hears the tone and lights flash, you found the matching end

This is very useful when hundreds of cables look identical.

### Punch-Down Tool

A **punch-down tool** terminates wires onto a punch-down block.

It:

- Presses each wire into the block contacts
- Holds the wire securely
- Trims excess wire for a clean install

Best practice:

- Keep twists as close as possible to the block to reduce interference
- Number and document punch-down positions
- Record where the other end of each cable goes

That documentation makes later switch connections much easier.

### Cable Tester

A **cable tester** checks whether a cable is wired correctly.

For a straight patch cable, you want:

- Pin 1 to pin 1
- Pin 2 to pin 2
- and so on through pin 8

A tester checks continuity and can reveal:

- Missing pins
- Crossed wires
- Incorrect pin mapping

Cable testers are usually simple continuity tools. They are not full signal-quality analyzers, but they quickly confirm wiring order.

Some tone generator kits also include cable-testing mode and light up pins 1–8 as they verify continuity.

### Loopback Plug

A **loopback plug** tests a physical interface on a device.

There are versions for:

- Serial
- RJ45
- Fiber

A loopback is not a crossover cable. It loops the interface’s transmit back into its receive path.

Typical use:

1. Plug the loopback into the interface
2. Put the interface into diagnostic mode
3. Send test data out
4. Confirm the same data comes back in

If sent and received data do not match, the physical interface may be faulty. This helps separate bad hardware from a bad cable.

### Network Tap and SPAN

A **network tap** is placed in the middle of a link to copy traffic for analysis.

Notes:

- Installing a tap usually means briefly breaking the link
- Permanent taps are useful on links that are monitored often
- Many fiber taps are passive and need no power
- Some copper taps need power

If you cannot interrupt a production link, use a switch feature instead:

- Port mirror
- Port redirection
- **SPAN** — Switched Port Analyzer

With SPAN, you connect an analyzer to one switch port and tell the switch to copy frames from another port to that analyzer port. The switch acts like a software tap.

## Common Mix-Ups

### Cable Tester vs Loopback Plug

- Cable tester = checks the cable wiring
- Loopback plug = checks the device interface

### Tone Generator vs Cable Tester

- Tone generator = identifies which cable is which
- Cable tester = verifies pin-to-pin continuity

### Physical Tap vs SPAN

- Tap = hardware inserted into the link
- SPAN = switch copies traffic to a monitoring port

### Crimper vs Punch-Down Tool

- Crimper = installs an end connector such as RJ45
- Punch-down tool = terminates wires into a block
