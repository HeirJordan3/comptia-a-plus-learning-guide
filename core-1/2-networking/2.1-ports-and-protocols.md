# Ports and Protocols

CompTIA A+ Core 1 — 220-1201  
Objective 2.1 — Compare and contrast Transmission Control Protocol (TCP) and User Datagram Protocol (UDP) ports, protocols, and their purposes

## What You Need to Know

By the end of this lesson, you should recognize these common ports and why they matter:

- FTP — TCP 20 and 21
- SSH — TCP 22
- Telnet — TCP 23
- SMTP — TCP 25
- DNS — UDP 53
- DHCP — UDP 67 and 68
- HTTP — TCP 80
- HTTPS — TCP 443
- POP3 — TCP 110
- IMAP — TCP 143
- SMB / NetBIOS-related ports — UDP 137, TCP 139, TCP 445
- LDAP — TCP 389
- LDAPS
- RDP — TCP 3389

You should also understand why each protocol is used on a network.

## What Is It?

Applications commonly use a **well-known port number** for network communication.

A port helps the computer know which service a packet is meant for. TCP and UDP both use port numbers.

For CompTIA A+, memorize:

- The port number
- The protocol
- Why that protocol matters

## Why Does It Matter?

Help desk and IT support technicians use port knowledge for:

- Troubleshooting communication problems
- Configuring firewalls
- Understanding which service is blocked or open
- Recognizing CompTIA exam scenarios

Example:

If web browsing fails over HTTPS, TCP 443 may be involved.  
If remote desktop fails, TCP 3389 may be involved.

## Real-World Analogy

Think of an office building with a main street address and many room numbers.

- The IP address is like the building address
- The port number is like the room number

Mail can reach the building, but it still needs the right room to reach the correct service.

## How It Works

### Why Port Numbers Matter

Firewalls often allow or block traffic based on TCP and UDP port numbers.

When you troubleshoot, knowing common ports helps you ask better questions:

- Is the service reachable?
- Is the firewall blocking the expected port?
- Is the client using the correct protocol?

These numbers can feel tedious at first. With practice, they become second nature.

### FTP — TCP 20 and 21

FTP stands for File Transfer Protocol.

FTP transfers files between devices and can work across many operating systems.

| Port | Role |
| --- | --- |
| TCP 20 | Often used for active data transfer |
| TCP 21 | Often used for administration / control |

FTP may require:

- Username
- Password
- Another authentication factor

It can also support anonymous or generic login.

FTP is more than a simple file copy tool. It can:

- List files in a directory
- Add files
- Delete files
- Rename files
- Perform other administration tasks

### SSH — TCP 22

SSH stands for Secure Shell.

SSH provides an encrypted command-line connection to a remote device over **TCP 22**.

Use SSH when you need to administer a device securely across the network.

### Telnet — TCP 23

Telnet stands for Telecommunications Network.

Telnet commonly uses **TCP 23**.

Visually and functionally, Telnet looks similar to SSH:

- Command-line access
- Username and password login
- Remote administration

Major difference:

- SSH encrypts the session
- Telnet sends traffic in the clear

Most organizations avoid Telnet and prefer SSH. You may still see Telnet on very old systems that do not support SSH.

### SMTP — TCP 25

SMTP stands for Simple Mail Transfer Protocol.

SMTP commonly uses **TCP 25** to send email from one mail server to another.

Devices may also be configured to send mail to a server using SMTP.

To receive email on a client, protocols such as POP3 or IMAP are commonly used.

### DNS — UDP 53

DNS stands for Domain Name System.

People type names like `www.professormesser.com`, not long IP addresses. DNS translates a fully qualified domain name into an IP address.

DNS commonly uses **UDP 53**.

Because DNS is so important, networks often use multiple DNS servers for redundancy.

### DHCP — UDP 67 and 68

DHCP stands for Dynamic Host Configuration Protocol.

DHCP automatically assigns:

- IP address
- Subnet mask
- Default gateway
- DNS server settings
- Other configuration details

| Device | Port |
| --- | --- |
| DHCP server | UDP 67 |
| DHCP client | UDP 68 |

A device leases an address for a period of time. When the lease ends, it can renew it or return the address to the pool.

Administrators can also create reservations so printers or servers always receive the same IP address through DHCP.

### HTTP and HTTPS — TCP 80 and 443

| Protocol | Meaning | Port |
| --- | --- | --- |
| HTTP | Hypertext Transfer Protocol | TCP 80 |
| HTTPS | Hypertext Transfer Protocol Secure | TCP 443 |

- HTTP sends web traffic in the clear
- HTTPS encrypts web communication

Many sites use HTTPS today, but some services still use HTTP on port 80.

### POP3 and IMAP — TCP 110 and 143

These protocols are commonly used to receive email on a client.

| Protocol | Full Name | Port | Remember |
| --- | --- | --- | --- |
| POP3 | Post Office Protocol version 3 | TCP 110 | Downloads email to the client |
| IMAP / IMAP4 | Internet Message Access Protocol version 4 | TCP 143 | Better multi-client mailbox management |

IMAP adds useful features such as:

- Managing the inbox from multiple clients
- Creating folders
- Moving messages
- Synchronizing mailbox changes across devices

### SMB and Related Windows Ports

SMB stands for Server Message Block. You may also see CIFS, Common Internet File System.

SMB is commonly used in Windows environments for:

- File transfers
- Printer queues
- Other Windows-to-Windows communication

Older Windows communication used NetBIOS over TCP/IP:

| Port | Role |
| --- | --- |
| UDP 137 | NetBIOS name service |
| TCP 139 | NetBIOS session / file transfer setup |

Modern Windows often uses direct communication without NetBIOS. That NetBIOS-less communication commonly uses **TCP 445**.

### LDAP and LDAPS — TCP 389

LDAP stands for Lightweight Directory Access Protocol.

LDAPS is the secure version.

LDAP commonly uses **TCP 389**.

Organizations use directory services to store information about:

- Users
- Devices
- Resources

Directories are often organized into categories such as:

- Organization
- Organizational unit
- Common name

Example ideas:

- Production OU
- Support OU
- Engineering OU
- Common names such as Sam or Daniel

A very common LDAP use case is Microsoft Active Directory.

### RDP — TCP 3389

RDP stands for Remote Desktop Protocol.

RDP commonly uses **TCP 3389**.

It lets technicians:

- View a remote desktop
- Control a remote Windows computer
- Run a single remote application

RDP is mainly associated with Windows, but clients exist for macOS, Linux, Unix, iPhone, and other systems.

| Protocol | Port(s) | Purpose |
| --- | --- | --- |
| FTP | TCP 20 / 21 | File transfer and file administration |
| SSH | TCP 22 | Encrypted remote command-line access |
| Telnet | TCP 23 | Unencrypted remote command-line access |
| SMTP | TCP 25 | Send email between servers |

## Common Mix-Ups

### SSH vs Telnet

- SSH = encrypted, TCP 22
- Telnet = not encrypted, TCP 23

### HTTP vs HTTPS

- HTTP = TCP 80, in the clear
- HTTPS = TCP 443, encrypted

### POP3 vs IMAP

- POP3 = commonly TCP 110
- IMAP = commonly TCP 143, better multi-client management

### SMTP vs POP3 / IMAP

- SMTP = send mail
- POP3 / IMAP = receive mail on a client

### DNS vs DHCP

- DNS = names to addresses, UDP 53
- DHCP = automatic network configuration, UDP 67/68

### TCP 139 vs TCP 445

- 139 = older NetBIOS-based communication
- 445 = modern direct SMB communication
