# Assigning IP Addresses

CompTIA A+ Core 1 — 220-1201  
Objective 2.6 — IP Addressing

## What You Need to Know

By the end of this lesson, you should understand:

- The main IP configuration settings a device needs
- What a subnet mask and default gateway do
- Static vs dynamic IP addressing
- Why manual static addressing does not scale well
- DHCP reservations
- What APIPA is and when it appears
- The APIPA address range
- How a device checks that an APIPA address is free

## What Is It?

Assigning an IP address can be done in different ways:

- Manually configure a static address
- Use DHCP for automatic addressing
- Use a DHCP reservation for a consistent address through DHCP
- Fall back to APIPA when DHCP is unavailable

This lesson explains those strategies and the settings that make IP communication work.

## Why Does It Matter?

Help desk technicians constantly see IP assignment issues:

- Wrong subnet mask
- Missing default gateway
- Device keeps changing addresses
- Printers and servers need consistent addresses
- A laptop shows `169.254.x.x` and has no internet

Recognizing these patterns helps you fix connectivity faster.

## Real-World Analogy

Think of moving into an apartment building:

- IP address = your apartment number
- Subnet mask = which building/floor group you belong to
- Default gateway = the front desk that gets you to the outside world
- DHCP = the front desk assigns rooms automatically
- Reservation = the front desk always gives you the same room
- APIPA = temporary hallway badge when the front desk is closed

## How It Works

### Required IP Settings

To configure a device for IP communication, you usually need at least:

| Setting | Purpose |
| --- | --- |
| IP address | Unique address for the device |
| Subnet mask | Tells the device which local subnet it is on |
| Default gateway | Local router used to leave the subnet |

Example:

- IP address: `192.168.1.165`
- Subnet mask: `255.255.255.0`
- Default gateway: `192.168.1.1`

An IP subnet is the combination of an IP address and its subnet mask.

The subnet mask is not something devices commonly advertise across the network, so you often confirm it with the network administrator.

You may also configure:

- DNS servers
- NTP servers
- VoIP servers
- Other network options

### Static IP Addressing

A **static IP address** does not change.

One way to assign it is to type the settings manually on the device:

- IP address
- Subnet mask
- Gateway
- Preferred DNS
- Other options

Manual entry must be exact. A typing mistake can break network communication.

#### Why Manual Static Addressing Does Not Scale

If the gateway or DNS servers change, every manually configured device may need to be updated one by one.

That may be fine for a few home devices. It does not scale well for hundreds or thousands of company devices.

### DHCP Reservations

A better way to keep a consistent address is a **DHCP reservation**.

On the DHCP server, administrators link:

MAC address → reserved IP address

The device still uses DHCP, but always receives the same reserved address.

Benefits:

- Central management
- Device keeps the same IP
- Gateway/DNS changes can be updated on the DHCP server
- Next time the device starts, it gets the new settings automatically

This is common for:

- Printers
- Routers
- Switches
- Firewalls
- Other important infrastructure devices

### Dynamic Addressing with DHCP

Most everyday devices use DHCP.

At home, work, hotels, and coffee shops, DHCP usually assigns addresses automatically.

### APIPA When DHCP Fails

If a device is set for DHCP but no DHCP server responds, many operating systems assign an **APIPA** address.

APIPA stands for Automatic Private IP Addressing.

It is also called an IPv4 **link-local** address.

What APIPA can do:

- Communicate with other devices on the local subnet

What APIPA cannot do:

- Route outside the local subnet
- Provide normal internet access through a gateway

That makes APIPA useful for local troubleshooting while you investigate why DHCP failed.

### APIPA Address Range

APIPA uses:

```text
169.254.0.0 through 169.254.255.255
```

The standard reserves the first and last 256 addresses, so devices commonly receive:

```text
169.254.1.0 through 169.254.254.255
```

If you see a `169.254.x.x` address, the device likely could not reach DHCP.

### How a Device Picks an APIPA Address

When assigning APIPA, the device chooses a random address in the range and checks whether anyone else is using it.

It does this with an **ARP** request on the local network.

Example:

1. Device randomly chooses `169.254.77.77`
2. Sends an ARP broadcast asking if anyone already has that address
3. If nobody answers, it uses the address

### When to Prefer Static or Reserved Addresses

If a DHCP address keeps changing and that causes problems, use something more consistent.

Corporate networks often use:

- Manual static addressing, or more commonly
- DHCP reservations

Reservations give consistency without visiting every device to retype settings.

## Key Terms

| Term | Meaning |
| --- | --- |
| IP address | Unique host address on the network |
| Subnet mask | Identifies the local subnet |
| Default gateway | Router used to leave the local subnet |
| Static IP | Address that does not change |
| Dynamic IP | Address assigned automatically, usually by DHCP |
| DHCP reservation | DHCP always gives the same IP to a MAC address |
| APIPA | Automatic Private IP Addressing / IPv4 link-local |
| ARP | Used to check whether an IP is already in use |

## Common Mix-Ups

### Static IP vs DHCP Reservation

- Static IP = configured manually on the device
- DHCP reservation = DHCP still assigns it, based on MAC address

### APIPA vs Normal Private Address

- `192.168.x.x`, `10.x.x.x`, and `172.16–31.x.x` are normal private ranges
- `169.254.x.x` is APIPA / link-local fallback

### Gateway vs DNS

- Gateway = path out of the local subnet
- DNS = name resolution
