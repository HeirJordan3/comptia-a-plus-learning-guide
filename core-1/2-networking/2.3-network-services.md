## What Is It?

A network is more than cables and Wi-Fi.

It takes many **network services** to keep everyday work running. Some services help devices get addresses. Others share files, print documents, send email, check logins, filter spam, or balance traffic across servers.

This lesson is a map of common services you should recognize for CompTIA A+ and help desk work.

## Why Does It Matter?

Help desk technicians constantly hear symptoms like:

- “I can ping the IP, but the website name fails.”
- “My computer has no network settings.”
- “I cannot open the shared drive.”
- “Print jobs are stuck.”
- “Email is down.”
- “My login works on one system but not another.”

Recognizing which service is involved helps you troubleshoot faster and recognize CompTIA-style scenarios.

## Real-World Analogy

Think of a busy office building.

- Reception tells visitors where to go → DNS
- Badges and check-in control access → Authentication
- Mailroom handles messages → Mail server / spam gateway
- Shared filing cabinets hold documents → File sharing
- Security desk watches cameras and logs → Syslog / SIEM
- Multiple cashiers share the line → Load balancer

Different services, one working organization.

## How It Works

### DNS

DNS stands for Domain Name System.

When you type a name like `google.com` or `professormesser.com`, DNS helps convert that fully qualified domain name into an IP address. It can also support reverse lookups and other related information.

DNS is distributed across many servers on the internet. Organizations may also run internal DNS servers.

For deeper DNS practice, continue with the [DNS Configuration](2.4-dns-configuration.md) lesson.

### DHCP

DHCP stands for Dynamic Host Configuration Protocol.

DHCP automatically assigns IP addresses and other network settings when a device starts. Users do not have to type those settings manually.

Home networks and enterprise networks both use DHCP. Enterprises often run multiple DHCP servers for redundancy.

For deeper DHCP practice, continue with the [DHCP](2.4-dhcp.md) lesson.

### File Sharing

File sharing provides a central place to store documents so people can access them.

Common examples:

- Spreadsheets
- Documents
- Shared folders inside or outside the organization

Common protocols include:

- SMB — Server Message Block, common in Windows environments
- AFP — Apple Filing Protocol, historically common with macOS

Users often do not see the protocol. They just open a folder, drag files, rename items, and save changes.

### Print Servers

A print server manages print jobs.

It can:

- Receive print jobs
- Queue them
- Send them to printers successfully

The print service may run on:

- A separate computer connected to the printer
- Software built into the printer
- A network card that includes print service features

Network printing protocols may include:

- SMB
- IPP — Internet Printing Protocol
- LPD — Line Printer Daemon

### Mail Servers

Mail servers send and receive email.

They may be:

- Cloud-hosted by a provider
- Local servers in a data center

Email usually has a high uptime expectation. Users expect it to keep working, so administrators design mail services for strong availability.

### Syslog and SIEM

Network devices create log files. Switches, routers, servers, and firewalls all generate useful event data.

**Syslog** is a common way to send those logs to a central place.

A **SIEM** is a Security Information and Event Manager. It consolidates logs and helps correlate events across many systems.

Because so many logs are stored for a long time, syslog and SIEM systems often need a large amount of storage.

### Web Servers

A web server responds to browser requests.

Common protocols:

- HTTP — Hypertext Transfer Protocol
- HTTPS — Hypertext Transfer Protocol Secure

Web pages are often built with HTML, Hypertext Markup Language. The browser retrieves those files, interprets the HTML, and displays the page.

### Authentication Servers

An authentication server checks usernames and passwords and grants access to services.

You may also hear **AAA**:

- Authentication
- Authorization
- Accounting

Authentication is usually based on a centralized database so administrators can manage users from one place.

Home networks often skip a dedicated authentication server. Enterprises rely on it heavily and often use redundant authentication servers because so many resources depend on login success.

### Database Servers

Database servers store information in tables.

You can think of tables like large spreadsheets that can connect to each other. When tables relate to one another, the result is a relational database.

A common language for working with databases is **SQL**, Structured Query Language. Examples include Microsoft SQL Server and MySQL.

### NTP

NTP stands for Network Time Protocol.

NTP keeps date and time accurate across systems.

That matters for:

- Comparing log files across devices
- Encryption and security technologies that depend on correct time

NTP servers reference a reliable clock. Local computers run NTP clients and check in periodically to stay synchronized.

### Spam Gateway

A spam gateway evaluates incoming email and helps separate spam from legitimate messages.

It may run in the cloud or on a separate server. The process is not perfect, so users sometimes check the spam folder for real messages that were filtered by mistake.

### All-in-One Security Appliances

Many organizations place an all-in-one security appliance between the internal network and the internet.

You may also hear:

- Next-generation firewall
- UTM — Unified Threat Management
- Web security gateway

These devices can combine many functions, such as:

- URL filtering / content inspection
- Malware detection
- Spam filtering
- Firewall features
- IPS features
- Bandwidth shaping
- VPN support
- Routing and switching interfaces
- Older WAN connectivity options such as CSU/DSU

### Load Balancers

A load balancer shares traffic across multiple systems.

Example:

```text
Incoming web requests
        ↓
   Load balancer
   /     |     \
Web1   Web2   Web3
```

If one server fails, the load balancer removes it from rotation. The remaining servers keep handling traffic. When the failed server is repaired and returned, the load balancer can start sending requests to it again.

Users often never notice the outage.

### Proxy Servers

A proxy server makes requests on behalf of a client.

Typical flow:

1. Client sends a request to the proxy
2. Proxy requests the service
3. Proxy receives and evaluates the response
4. If the response is acceptable, the proxy sends it to the client

Proxies can help with:

- Security
- Access control
- Caching
- Content scanning

Users may not realize a proxy is in the path.

### SCADA / ICS

SCADA stands for Supervisory Control and Data Acquisition.

You may also hear ICS, Industrial Control System.

These systems manage large industrial equipment such as power, oil and gas, or manufacturing systems. They allow remote viewing, management, and control across the network.

Because the systems are critical, organizations usually keep them on a highly segmented and tightly controlled network.

### Legacy Systems

Legacy systems are older systems that are still in use.

A system may be 10, 15, 20 years old or older and still matter. Age alone does not make a system unimportant. Learning how to support legacy systems can be just as important as supporting new ones.

### Embedded Systems

An embedded system is a purpose-built device. Users often do not directly access the operating system.

Examples:

- Fire alarm systems
- Time clock systems

The manufacturer usually provides the tools needed to support the device. Many embedded systems need little day-to-day maintenance.

### IoT Devices

IoT stands for Internet of Things.

This is a broad category that can include:

- Smart appliances
- Voice-controlled devices
- HVAC controls
- Smart doorbells
- Garage door systems

A common challenge is security. The company that builds a refrigerator or thermostat may not specialize in network security. For that reason, IoT devices are often placed on a segmented network to limit damage if one is compromised.

## Common Mix-Ups

### DNS vs DHCP

- DNS finds addresses for names
- DHCP gives devices their network configuration

### Syslog vs SIEM

- Syslog moves/collects logs
- SIEM consolidates and correlates them for security and analysis

### Proxy vs Load Balancer

- Proxy sits between client and service for security, control, or caching
- Load balancer spreads work across multiple servers for availability

### Embedded vs IoT

- Embedded = purpose-built device, often little direct OS access
- IoT = internet-connected devices such as appliances and smart controls

### Legacy vs Broken

- Legacy means older, not useless
- Many legacy systems remain critical
