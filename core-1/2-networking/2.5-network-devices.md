## What Is It?

A data center or computer room is full of devices that each play a role in keeping traffic flowing.

Sometimes these roles are separate devices. Sometimes they are combined. A home wireless router is often a router, switch, access point, and security device in one box.

This lesson looks at the separate roles so you can recognize each one.

## Why Does It Matter?

Help desk technicians constantly work with:

- Switches and ports
- Access points
- Firewalls
- Modems and fiber ONTs
- PoE phones and cameras
- NICs on desktops and servers

Knowing what each device does helps you isolate problems faster.

## Real-World Analogy

Think of a city transportation system:

- Router = highway interchange between neighborhoods
- Switch = local street intersections inside one neighborhood
- Access point = wireless on-ramp
- Patch panel = labeled junction box that keeps long wires permanent
- Firewall = security checkpoint
- Modem / ONT = connection from the city into your building
- NIC = the vehicle’s own entrance onto the road

## How It Works

### Router

A **router** forwards traffic based on the destination **IP address**.

It uses a routing table to decide which interface should send the packet next.

Routers can also connect different network types, such as:

- Ethernet to wireless
- Fiber to copper
- Wireless to serial

Some devices combine routing and switching. Because routers work at OSI Layer 3, these are often called **Layer 3 switches** or multilayer switches.

### Switch

A **switch** connects wired end devices and forwards traffic based on the destination **MAC address**.

Switches are fast because much of the work happens in hardware, often using an **ASIC** (Application-Specific Integrated Circuit).

Common sizes:

- Workgroup switches: 24 or 48 ports
- Core switches: hundreds of interfaces

Many switches also support:

- Power over Ethernet
- Routing features in Layer 3 / multilayer switches

### Unmanaged Switch

An **unmanaged switch** is basically plug-and-play.

Characteristics:

- Little or no configuration
- No VLAN setup
- Usually no SNMP management
- Usually no logs
- Lower cost

Effectively, the whole switch acts like one big VLAN.

### Managed Switch

A **managed switch** is designed for enterprise control.

It may support:

- VLANs on different interfaces
- Traffic prioritization
- Redundancy between switches
- Remote management through SNMP or direct configuration
- Port mirroring for monitoring or security tools

**Port mirroring** copies traffic from one interface to another so an analyzer or security device can inspect it.

### Access Point

An **access point** connects wireless devices to a wired network.

This is different from a home wireless router. An access point is not primarily a router. It bridges wireless and wired networks.

Because it bridges:

- There is usually no IP translation/routing in that role
- Forwarding is based on MAC addresses, similar to a switch

It decides whether a frame stays on the wireless side or goes to the wired side.

### Patch Panel

In an office, desk Ethernet cables usually run back to a closet and terminate on a **patch panel**.

Why that matters:

- The long run from desk to closet stays permanent
- The closet side uses short patch cables into switches
- Moves between switches or VLANs happen in the closet without rewiring desks

Typical flow:

```text
Desk jack  --->  permanent cable  --->  patch panel  --->  short patch cable  --->  switch
```

### Firewall

A traditional **firewall** allows or blocks traffic based on TCP/UDP port numbers and access lists.

A **next-generation firewall** can also make decisions based on the application itself, not just the port.

Example:

- Allow web traffic
- Block remote-access software

Based on the application behavior, not only the port number.

Firewalls may also act as:

- VPN concentrators for site-to-site or remote access VPNs
- Proxies that inspect responses before sending them to clients
- Routers between many IP subnets

### Power over Ethernet (PoE)

**PoE** sends data and power over the same Ethernet cable.

Common PoE devices:

- Desk phones
- Wireless access points
- Cameras
- Some laptops with higher PoE standards

#### Endspan vs Midspan

| Term | Meaning |
| --- | --- |
| Endspan | PoE power comes from the switch itself |
| Midspan | PoE power comes from an injector placed in the cable path |

If a switch does not support PoE, an injector can add power in the middle of the run.

#### PoE Standards

| Standard | Power (approx.) | Notes |
| --- | --- | --- |
| PoE | 15.4 W DC / 350 mA | Good for phones and smaller devices |
| PoE+ | 25.5 W DC / 600 mA | More power for devices like PTZ cameras |
| PoE++ | 51 W or 71.3 W depending on mode | Higher power; associated with newer copper Ethernet capabilities |

These standards are downward compatible, not upward. A device that needs PoE++ will not run on PoE or PoE+ alone.

### Cable Modem

A **cable modem** provides internet over a cable television broadband coax link and usually presents Ethernet on the customer side.

You may hear **DOCSIS**: Data Over Cable Service Interface Specification.

Cable modem links commonly support 1 Gbps and higher and are used in homes and some businesses.

### DSL Modem

**DSL** stands for Digital Subscriber Line.

It uses traditional telephone wiring to carry digital internet service along with analog phone service.

Typical idea from the lesson:

- Around 200 Mbps down / 20 Mbps up is possible on many DSL networks
- Distance to the central office matters
- About 10,000 feet is a practical limitation
- Closer usually means faster

### ONT

An **ONT** is an Optical Network Terminal.

It converts fiber coming into a home or business into copper/network connections you can use locally.

The ONT is often at the **demarcation point (demarc)**.

The demarc marks responsibility:

- Inside wiring = customer responsibility
- Outside provider network = ISP responsibility

An ONT may provide:

- RJ45 Ethernet data
- RJ11 voice connections
- Coax / F-connector video output

### NIC

A **NIC** is a Network Interface Card.

It connects a computer or server to the Ethernet network.

NICs may be:

- Built into a motherboard
- Added as expansion cards
- Copper or fiber
- Single or multi-port

Each Ethernet interface has its own **MAC address** so it can be uniquely identified on the local network.

## Common Mix-Ups

### Router vs Switch

- Router = IP decisions between networks
- Switch = MAC decisions within a local network

### Access Point vs Wireless Router

- Access point = mainly bridges wireless and wired
- Home wireless router = often router + switch + AP + security combined

### Unmanaged vs Managed Switch

- Unmanaged = simple and cheap
- Managed = configurable and enterprise-ready

### Endspan vs Midspan

- Endspan = switch provides PoE
- Midspan = injector provides PoE

### Modem vs Router

- Modem/ONT = brings the ISP link into the building
- Router = forwards between IP networks
