## What Is DHCP?

DHCP stands for Dynamic Host Configuration Protocol.

DHCP automatically provides network configuration to devices. That configuration may include:

- IP address
- Subnet mask
- Default gateway
- DNS server
- Lease information
- Other network options

### Real-World Example

When someone connects a laptop to Wi-Fi at a coffee shop, they normally do not manually configure an IP address. DHCP handles much of that configuration automatically.

A useful comparison:

- DNS helps you find an address.
- DHCP gives you your network configuration.

## Why Does It Matter?

Help desk technicians constantly see DHCP-related issues:

- A device cannot get an IP address
- A device received the wrong gateway or DNS settings
- A printer needs the same address every time
- An address should never be handed out dynamically

Understanding DHCP helps you explain connectivity problems and configure networks more reliably.

## Static vs Dynamic

### Static Configuration

A static IP address is configured manually on the device.

This can be useful for some servers, printers, or network devices, but it requires careful tracking and more manual work.

### Dynamic Configuration

With DHCP, a device can request network settings automatically.

This is faster for most users and reduces configuration mistakes.

## How It Works

### DORA

DHCP uses a four-step process often remembered as **DORA**.

```text
CLIENT                    DHCP SERVER

Discover  -------------->
          Anyone there?

          <-------------- Offer
          Use this address.

Request   -------------->
          I'll take it.

          <-------------- Acknowledge
          It's yours.
```

What each step means:

- Discover = Find DHCP
- Offer = Here is an address
- Request = I want that one
- Acknowledge = Approved

### Broadcast

At the beginning of the process, the client often uses broadcast communication.

Why? Because the client does not yet know the DHCP server and may not have normal IP configuration yet.

Analogy: Walking into a room and asking, “Is anyone here who can help me?”

The Discover message is that kind of question.

- Server = 67

### DHCP Scope

A **scope** is the overall DHCP configuration for a network.

It may include:

- IP address range
- Exclusions
- Subnet mask
- Lease duration
- DNS server
- Default gateway
- Other configuration options

### Pool

A **pool** is the set of addresses available for DHCP assignment.

### Exclusion

An **exclusion** marks addresses that DHCP should not dynamically assign.

Example: A router address should not be handed out to a laptop.

### Lease

A **lease** is a temporary assignment of an IP address.

Hotel analogy: You use the room for a period of time, but you do not own it.

When the lease ends, the address may be renewed or returned to the pool.

### Reservation

A **reservation** allows a particular device to receive the same IP address through DHCP.

DHCP associates:

MAC address → Reserved IP address

You may also hear:

- DHCP reservation
- IP reservation
- Static DHCP assignment

Important clarification: A DHCP reservation is not identical to manually configuring a static IP on the device. With a reservation, DHCP still assigns the address, but always the same one for that MAC address.

## Common Mix-Ups

### DHCP vs DNS

- DHCP gives a device its network configuration
- DNS translates names into addresses

### Scope vs Pool

- Scope = overall DHCP configuration
- Pool = available addresses for assignment

### Lease vs Reservation

- Lease = temporary use of an address
- Reservation = same device gets the same address through DHCP

### Static IP vs DHCP Reservation

- Static IP = configured manually on the device
- DHCP reservation = DHCP still assigns the address, based on MAC address
