# Motherboard Form Factors

CompTIA A+ Core 1 — 220-1201  
Objective 3.5 — Motherboards, CPUs, and Add-on Cards

## What You Need to Know

By the end of this lesson, you should understand:

- Why motherboard form factor matters
- What an ATX motherboard is
- What a microATX motherboard is
- What an ITX / Mini-ITX motherboard is
- How size affects expansion slots, memory slots, and use cases
- Why mounting points and power connectors often stay compatible across these standards

## What Is It?

A **motherboard form factor** is the physical size and layout standard for a motherboard.

Desktops, small-office PCs, and media-center systems can contain similar parts — CPU, memory, storage, network — but the motherboard footprint changes a lot.

For CompTIA A+ Core 1, focus on three form factors:

- ATX
- microATX
- ITX (especially Mini-ITX)

## Why Does It Matter?

Choosing the wrong board for the case or job causes install and upgrade problems:

- Board will not fit the case
- Not enough expansion slots for add-on cards
- Not enough memory slots
- Cooling / airflow is harder in a tiny chassis
- Wrong choice for a media PC next to a TV vs a full desktop editing workstation

Exam scenarios often ask which motherboard fits a given situation.

## Real-World Analogy

Think of motherboards like kitchen countertops:

- **ATX** = a full kitchen island — room for many appliances and extras
- **microATX** = a smaller counter with the same basic layout, but fewer add-ons
- **Mini-ITX** = a compact apartment counter — fits tight spaces, limited extras

The mounting holes often line up so a smaller board can still sit in a larger “kitchen,” but you lose workspace.

## How It Works

### What Changes Between Form Factors

When comparing motherboards, consider:

| Factor | Why it matters |
| --- | --- |
| Physical size | Must fit the case |
| Component layout | Affects what fits on the board |
| Expansion options | Larger boards usually support more cards and RAM slots |
| Power connectors | Most follow standards, but not every board is identical |
| Airflow / cooling | Smaller systems can get hotter and need careful cooling |

There are many motherboard types in the industry. For A+, prioritize ATX, microATX, and ITX.

### ATX — Advanced Technology Extended

**ATX** is the largest of the three A+ focus types.

Key points:

- Standard since **1995**
- Current ATX is still similar to the original idea
- Early ATX main power used a **20-pin** connector
- Modern ATX usually uses a **24-pin** main power connector

Typical strengths of a full-size ATX board:

- More expansion slots
- More memory slots
- More room for components

Example idea from the lesson: a large Gigabyte ATX board with multiple expansion slots and four memory slots, with the CPU near the center.

### microATX

**microATX** (also written Micro-ATX) is similar in layout to ATX, but smaller.

Important compatibility notes:

- Mounting points often match full-size ATX mounting points
- Power connectors are commonly the same style as ATX
- Fits smaller cases while keeping ATX-like standards

Trade-off: less space means fewer resources.

Example idea from the lesson: an MSI microATX board with only one expansion slot and two memory slots.

When boards shrink, manufacturers choose what stays and what gets cut.

### ITX / Mini-ITX

**ITX** motherboards are the small form-factor family. The lesson focuses on **Mini-ITX**, one of the smallest common ITX sizes.

Key points:

- Very small footprint
- Often keeps the same mounting screw points as traditional ATX
- Can be installed in a case designed for ATX
- Ideal for tight spaces

Good use cases:

- Streaming / media device next to a TV
- Single-purpose compact PC

## Side-by-Side Comparison

| Form factor | Relative size | Typical idea |
| --- | --- | --- |
| ATX | Largest | Most expansion and flexibility |
| microATX | Medium | ATX-like layout in a smaller board |
| Mini-ITX | Smallest | Compact systems, limited expansion |

## Key Terms

| Term | Meaning |
| --- | --- |
| Form factor | Motherboard size and layout standard |
| ATX | Advanced Technology Extended; full-size desktop standard |
| microATX | Smaller ATX-compatible style board |
| ITX / Mini-ITX | Small form-factor motherboard family / common small size |
| 20-pin / 24-pin | Older vs modern ATX main power connectors |
| Expansion slot | Slot for add-on cards |
| Memory slot | Slot for RAM modules |
| Mounting points | Screw holes that secure the board in a case |

## Common Mix-Ups

### ATX vs microATX

- Similar layout and often similar mounting / power style
- microATX is smaller and usually has fewer slots and features

### Mini-ITX vs “ITX”

- ITX is the small form-factor family
- Mini-ITX is the common small size shown for A+ scenarios

### Case Size vs Board Size

A smaller board can often mount in a larger ATX case, but a full ATX board will not fit a tiny Mini-ITX case.

### Power Connector Assumptions

Most boards follow common standards, but always verify the power connection for the board you are installing.

## Quick Review

| Form factor | Remember |
| --- | --- |
| ATX | Largest, most flexible |
| microATX | Smaller ATX-like board |
| Mini-ITX | Smallest, tight-space builds |

| Trade-off | Smaller size = fewer components / slots |
