# RAID

CompTIA A+ Core 1 — 220-1201  
Objective 3.4 — Storage Devices

## What You Need to Know

By the end of this lesson, you should understand:

- What RAID means
- Why RAID is not a backup
- RAID 0 (striping)
- RAID 1 (mirroring)
- RAID 5 (striping with single parity)
- RAID 6 (striping with dual parity)
- RAID 10 / RAID 1+0 (stripe of mirrors)

## What Is It?

**RAID** stands for **Redundant Array of Independent Disks** (also called Redundant Array of Inexpensive Disks).

RAID combines multiple drives to improve:

- Throughput
- Redundancy (depending on the level)

Some RAID levels protect data if a drive fails. Some do not. Knowing the difference matters.

## Why Does It Matter?

Hard drives are mechanical and can fail. SSDs can fail too. Important data should stay available.

RAID helps keep systems running after drive failure — but:

> RAID is **not** a backup.

You still need a separate backup process.

## Real-World Analogy

Think of RAID like different ways to store important photos:

- **RAID 0** = split photos across albums for speed — lose one album, the set is incomplete
- **RAID 1** = keep two identical albums — lose one, the other still has everything
- **RAID 5 / 6** = split photos plus a recovery checklist — rebuild missing pieces from parity
- **RAID 10** = split sets, and each set has a duplicate album

## How It Works

### RAID 0 — Striping

**RAID 0** needs at least **two** drives.

Data is split across drives (striped). A file can be broken into blocks stored across multiple disks.

Strength:

- Fast writes/reads because work is shared across drives

Weakness:

- If one drive fails, data is lost / inaccessible
- Often remembered as **zero redundancy**

### RAID 1 — Mirroring

**RAID 1** needs at least **two** drives.

Everything written to one drive is duplicated on the other.

Strength:

- If one drive fails, the mirror still has all data
- System can keep working while you replace the failed drive and rebuild the mirror

Trade-off:

- Needs about twice the storage space for the same usable data

### RAID 5 — Striping with Parity

**RAID 5** uses striping like RAID 0, plus **parity**.

In a four-drive example from the lesson:

- Three drives hold data pieces
- One drive’s worth of capacity is used for parity (parity is distributed across drives)

If a drive fails:

- Remaining data + parity can recreate the missing data
- Array can keep running while degraded

Trade-offs:

- Better space efficiency than full mirroring
- Parity calculation uses CPU overhead, especially during recovery

### RAID 6 — Striping with Dual Parity

**RAID 6** is like RAID 5, but with **two** parity blocks / an extra parity drive’s worth of protection.

Strength:

- Can lose **two** drives and still keep data available (degraded state)

Trade-off:

- Extra drive capacity goes to parity, not usable storage growth in the same way

### RAID 10 (RAID 1+0) — Stripe of Mirrors

**RAID 10** combines:

- RAID 0 striping
- RAID 1 mirroring

Also written as **RAID 1+0**.

Basic idea:

- Stripe data across mirrored sets
- Requires at least **four** drives

Strength:

- Can lose multiple drives and stay up, as long as you do not lose both sides of the same mirrored pair

Example idea from the lesson: lose one drive from each mirrored set and still remain online because each stripe still has a surviving mirror.

## RAID Level Comparison

| RAID | Also called | Min drives idea | Redundancy | Main benefit |
| --- | --- | --- | --- | --- |
| 0 | Striping | 2+ | None | Speed |
| 1 | Mirroring | 2+ | Yes (full copy) | Simple redundancy |
| 5 | Striping + parity | Commonly 3+ (4-drive example in lesson) | Survives 1 drive loss | Efficiency + redundancy |
| 6 | Striping + dual parity | More drives than RAID 5 | Survives 2 drive losses | Stronger redundancy |
| 10 | Stripe of mirrors | 4+ | Yes, if mirrors survive | Speed + redundancy |

## Key Terms

| Term | Meaning |
| --- | --- |
| RAID | Redundant Array of Independent/Inexpensive Disks |
| Striping | Splitting data across multiple drives |
| Mirroring | Exact duplicate of data on another drive |
| Parity | Extra recovery information used to rebuild lost data |
| Nested RAID | Combining RAID levels (for example 1+0) |
| Degraded | Array still works after drive failure, but with reduced protection/performance |

## Common Mix-Ups

### RAID vs Backup

RAID keeps a system available after drive failure. Backups protect against deletion, corruption, ransomware, and site loss.

### RAID 0 vs RAID 1

- 0 = speed, no safety net
- 1 = safety net, uses more capacity

### RAID 5 vs RAID 6

Both use parity. RAID 6 has dual parity and can survive two drive failures.

### RAID 10 naming

RAID 10 and RAID 1+0 refer to nested mirroring + striping (stripe of mirrors).
