# Peripheral Cables

CompTIA A+ Core 1 — 220-1201  
Objective 3.2 — Cables and Connectors

## What You Need to Know

By the end of this lesson, you should understand:

- USB version speeds and common cable length ideas
- Common USB connector styles and why USB-C exists
- What serial / DB-9 connections are used for today
- How Thunderbolt versions differ in speed and connector type
- That USB-C is a connector shape, not one signal type

## What Is It?

Peripheral cables connect keyboards, mice, printers, storage, and other devices to a computer.

This lesson covers:

- USB
- USB-C
- Serial cables (DB-9 / RS-232)
- Thunderbolt

## Why Does It Matter?

Help desk technicians use these cables constantly:

- Wrong USB cable/connector for a printer or phone
- Console access to a switch/router when the network is down
- Thunderbolt docks and daisy-chained displays
- Confusion between USB-C the plug and Thunderbolt/USB the signal

## Real-World Analogy

Think of peripheral cables like different kinds of extension cords:

- **USB** = the everyday cord almost everything uses
- **USB-C** = one plug shape that can carry several kinds of “power/data recipes”
- **Serial / DB-9** = the old console key for network gear when nothing else works
- **Thunderbolt** = a high-speed cord that can carry data and power, and can chain devices

## How It Works

### USB — Universal Serial Bus

**USB** is the standard connection for most peripherals.

| Version | Speed idea | Cable length idea |
| --- | --- | --- |
| USB 1.1 Low Speed | 1.5 Mbps | About 3 meters |
| USB 1.1 Full Speed | 12 Mbps | About 5 meters |
| USB 2.0 | 480 Mbps | About 5 meters |
| USB 3.0 (SuperSpeed) | 5 Gbps | About 3 meters |
| USB 3.1 | 10 Gbps | — |
| USB 3.2 | 20 Gbps | — |

The USB spec does not lock exact cable lengths, but these distances are about the practical maximum for that throughput.

#### USB Connector Styles

| Era | Common connectors |
| --- | --- |
| USB 1.1 / 2.0 | Standard-A, Standard-B (more square), Mini-B, Micro-B |
| USB 3.0 | Standard-A similar; Standard-B a bit taller; Micro-B looks different from older Micro-B |

Too many connector types caused confusion, so the industry moved toward one reversible standard: **USB-C**.

### USB-C

**USB-C** describes the **physical connector**, not the signal.

Signals over USB-C may include:

- USB
- Thunderbolt
- HDMI
- Other supported modes

USB-C is similar in size to Micro-B and smaller than Standard-A. It can replace many older USB plug styles and does not require a specific orientation.

### Serial Cables

Before USB, peripherals often used **serial** cables.

Common connectors:

| Name | Notes |
| --- | --- |
| DB-25 | Larger B-size connector; 25 pins |
| DB-9 / DE-9 | Smaller E-size connector; commonly still called DB-9 |

Serial communication uses **RS-232** (Recommended Standard 232, since about 1969).

Older uses: modems, keyboards, mice, and other peripherals.

Modern uses: console ports on switches, routers, and firewalls for command-line configuration when other management paths fail.

Console port forms you may see:

- DB-9 serial
- RJ45 console port (serial, **not** Ethernet)
- USB console on newer gear

Because many PCs no longer have DB-9 ports, technicians often carry:

- USB / USB-C → DB-9 adapters
- Further adapters to RJ45 console cables when needed

### Thunderbolt

**Thunderbolt** is a high-speed serial connection that carries **data and power** on one cable.

| Version | Connector idea | Throughput idea |
| --- | --- | --- |
| Thunderbolt 1 | Mini DisplayPort | 2 × 10 Gbps channels = 20 Gbps total |
| Thunderbolt 2 | Mini DisplayPort | 20 Gbps aggregated |
| Thunderbolt 3 | USB-C | 40 Gbps aggregated |
| Thunderbolt 4 | USB-C | Still 40 Gbps aggregated; improved dual 4K video support and more PCIe bandwidth |

Thunderbolt 3 cable notes from the lesson:

- Copper: up to about **3 meters**
- Optical: up to about **60 meters**

Thunderbolt supports **daisy chaining**: computer → monitor → another monitor → external storage, and so on. The chain knows which device to talk to.

## Key Terms

| Term | Meaning |
| --- | --- |
| USB | Universal Serial Bus |
| USB-C | Physical connector type that can carry multiple signal types |
| Standard-A / B | Common older USB plug styles |
| Mini-B / Micro-B | Smaller USB plugs used on many devices |
| RS-232 | Serial communication standard |
| DB-9 / DE-9 | Common serial connector naming |
| Console port | Direct management port on network gear |
| Thunderbolt | High-speed data + power peripheral interface |
| Daisy chain | Linking devices one after another on one path |

## Common Mix-Ups

### USB version vs USB-C connector

USB 2.0 / 3.x are signaling generations. USB-C is the physical plug that may carry those or other protocols.

### RJ45 console vs Ethernet

Some console ports use RJ45 connectors but carry serial management traffic, not Ethernet LAN traffic.

### Thunderbolt vs USB on USB-C

Same USB-C shape can be Thunderbolt or USB depending on the port, cable, and device support.

### DB-9 vs DE-9

Same common 9-pin serial connector; naming differs, but people usually say DB-9.
