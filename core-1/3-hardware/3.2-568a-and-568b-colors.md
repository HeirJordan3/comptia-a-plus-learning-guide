# 568A and 568B Colors

CompTIA A+ Core 1 — 220-1201  
Objective 3.2 — Cables and Connectors

## What You Need to Know

By the end of this lesson, you should understand:

- Why Ethernet wiring uses standard color schemes
- What T568A and T568B are
- Which pins stay the same between A and B
- Which pins differ between A and B
- Why you should not mix A on one end and B on the other
- How keystone jacks show A and B punch-down colors

## What Is It?

Ethernet twisted-pair cables use standard wire colors so installations stay consistent worldwide.

The two common pin/color standards for eight-conductor RJ45 cabling are:

- **T568A**
- **T568B**

Both work on the same RJ45 connector style. The difference is which colors land on which pins.

## Why Does It Matter?

Technicians need these standards when:

- Crimping RJ45 connectors
- Punching down keystone jacks
- Troubleshooting a cable that was terminated incorrectly
- Matching an organization’s existing wiring standard

Mixing standards or getting colors wrong causes failed links and wasted time.

## Real-World Analogy

Think of T568A and T568B like two accepted ways to lace the same pair of shoes.

Same shoes, same eight eyelets — but the lace colors start in different places. Once a building chooses one method, everyone should keep using that method so every cable matches.

## How It Works

### Standards Behind the Colors

International cabling classes are managed in documents such as **ISO/IEC 11801**.

In the U.S., the **TIA** (Telecommunications Industry Association) defines commercial building cabling in **ANSI/TIA-568**. That standard defines the pin/color layouts known as:

- T568A
- T568B

Organizations usually pick one and stay with it. In the U.S., **T568B is the more common** choice.

### Do Not Mix A and B on One Cable

Do not terminate one end as T568A and the other end as T568B.

Some internet sources call that a “crossover cable,” but checking the pinouts shows that mixing A and B is not the correct way to make a proper Ethernet crossover. Keep both ends on the same standard.

### Pinout Comparison

Both standards use eight conductors. Blue and brown pairs stay on the same pins. Orange and green pairs swap roles.

#### T568A

| Pin | Color |
| --- | --- |
| 1 | White/Green |
| 2 | Green |
| 3 | White/Orange |
| 4 | Blue |
| 5 | White/Blue |
| 6 | Orange |
| 7 | White/Brown |
| 8 | Brown |

#### T568B

| Pin | Color |
| --- | --- |
| 1 | White/Orange |
| 2 | Orange |
| 3 | White/Green |
| 4 | Blue |
| 5 | White/Blue |
| 6 | Green |
| 7 | White/Brown |
| 8 | Brown |

#### What Stays the Same

| Pins | Colors (same on A and B) |
| --- | --- |
| 4 and 5 | Blue / White-Blue |
| 7 and 8 | White-Brown / Brown |

#### What Changes

You mainly memorize the differences on:

- Pins **1 and 2**
- Pins **3 and 6**

### Identifying a Cable

You should be able to look at a terminated RJ45 and tell which scheme was used.

Example from the lesson: a cable showing white-orange / orange at the start matched **T568B**.

### Crimping Tip

Before you crimp:

1. Slide the wires into the RJ45
2. Visually check the color order against A or B
3. Pull out and fix if needed
4. Crimp only when the order is correct

Tiny wires are easy to get wrong once they are inside the connector.

### Keystone Jacks

Punch-down jacks often print both A and B color guides on the jack.

- A colors may be along the top
- B colors may be along the bottom

The printed order on the jack may not look identical to the RJ45 pin order. That is normal. The jack’s internal wiring maps those punch-down positions to the correct RJ45 pins.

Another common jack layout puts four wires on each side. Follow the A or B colors printed for that jack and stay consistent with the building standard.

## Common Mix-Ups

### T568A vs T568B

Same connector and same blue/brown pins. Orange and green pairs swap between A and B.

### Mixing A and B

Not a reliable “crossover shortcut.” Keep both ends on one standard.

### Jack Print vs RJ45 Pin Order

Jack labels are installation helpers. Internal jack wiring places signals on the correct RJ45 pins.

### “Any colors are fine if both ends match randomly”

Both ends must match a real standard, and that standard should match the rest of the building.
