# Motherboard Compatibility

CompTIA A+ Core 1 — 220-1201  
Objective 3.5 — Motherboards, CPUs, and Add-on Cards

## What You Need to Know

By the end of this lesson, you should understand:

- Why Intel and AMD CPUs need matching motherboard sockets
- That price vs performance marketing is a generalization
- How CPU installation into a socket usually works
- What makes server motherboards different from typical workstation boards

## What Is It?

Motherboard compatibility means matching the board to the CPU and system role.

This lesson focuses on:

- Intel-based vs AMD-based motherboards
- Common server motherboard specifications

The two major CPU companies in the PC space are **Intel** and **AMD**.

## Why Does It Matter?

Buying the wrong board for a CPU wastes money and time.

Common support scenarios:

- User bought an AMD CPU and an Intel-socket motherboard
- Desktop board used where a multi-CPU server board is needed
- Not enough memory slots or expansion for a server workload

## Real-World Analogy

Think of CPU sockets like different phone chargers:

- Intel and AMD chips may look similarly sized
- The connector pattern is different
- The right “charger” (motherboard socket) must match the phone (CPU)

Server boards are more like multi-bay workshop benches — room for more processors, memory, and add-on tools.

## How It Works

### Intel vs AMD Motherboards

Both Intel and AMD make CPUs used in PCs. They are competitors, and which one is cheaper or faster can change over time.

Generalized market idea from the lesson:

| Brand idea | Common perception |
| --- | --- |
| AMD | Often seen as lower-cost option |
| Intel | Often seen as higher-performance option |

Reality check from the lesson:

- These are generalizations
- Sometimes Intel has the better price
- Sometimes AMD has the better performance
- Specs shift as the companies compete

#### Socket Compatibility

Physical CPU sizes can look similar, but motherboard connectivity differs.

| If you plan to use… | You need… |
| --- | --- |
| An AMD CPU | A motherboard with an AMD socket |
| An Intel CPU | A motherboard with an Intel socket |

You cannot mix an Intel CPU with an AMD socket board (or the reverse).

### Installing a CPU

Installation is usually straightforward:

1. Place the CPU on the socket — no forcing
2. Close the cover
3. Lock it with the socket handle

Most processor sockets do **not** require pressure to seat the chip. If it seems to need force, stop and recheck orientation/compatibility.

### Server Motherboard Specs

Workstations and laptops usually have a single CPU. Servers often need more processing power.

Common server motherboard traits from the lesson:

| Feature | Why it matters |
| --- | --- |
| Multisocket support | Multiple physical CPUs on one board |
| Many memory slots | Often 4+ slots to maximize RAM |
| Multiple expansion slots | Customize the server for its role |
| Full-size ATX fit | Designed for 19-inch rack systems |

Example idea from the lesson: a server board with six memory slots, plenty of expansion, and support for two physical CPUs.

If you need lots of CPU power and RAM in one system, choose a motherboard designed for servers.

## Key Terms

| Term | Meaning |
| --- | --- |
| Intel / AMD | Major PC CPU manufacturers |
| Socket | Motherboard connector that matches a CPU family |
| Multisocket | Motherboard supports more than one physical CPU |
| Server motherboard | Board built for higher CPU/RAM/expansion needs, often rack/ATX |
| ATX | Full-size form factor commonly used in rack-mounted servers |

## Common Mix-Ups

### “Compatible with each other” vs same socket

Intel and AMD compete in the same PC market, but their sockets are different. Match CPU brand/family to the board socket.

### Price vs performance stereotypes

AMD ≠ always cheaper. Intel ≠ always faster. Check current specs for the build.

### Workstation vs server boards

A normal desktop board may not offer multi-CPU support or enough RAM/expansion for server roles.
