# DHCP Scenario Challenge

You are the new IT support technician for a small company.

## Network Details

- Network: `192.168.10.0/24`
- DHCP dynamic range: `192.168.10.100` – `192.168.10.199`
- Router: `192.168.10.1`
- Printer: `192.168.10.150`
- Printer MAC: `AA:BB:CC:11:22:33`

## Directions

Answer each question based on the scenario and what you learned about DHCP.

Write your answers on paper, in notes, or in a separate document. Do not look for an answer key on this page.

## Questions

1. What DHCP term describes `192.168.10.100` – `192.168.10.199`?

2. The router's address should never be dynamically handed to another device. What DHCP concept prevents selected addresses from being dynamically assigned?

3. The printer needs `192.168.10.150` every time it connects through DHCP. What should be configured?

4. What hardware address identifies the printer for the reservation?

5. Put these DHCP messages in the correct order:

   - REQUEST
   - ACKNOWLEDGE
   - DISCOVER
   - OFFER

6. Which device sends the initial Discover?

   A. DHCP server  
   B. Client  
   C. Router  
   D. DNS server

7. Which DHCP message essentially means, “I have an address available for you”?

   A. Discover  
   B. Request  
   C. Offer  
   D. Acknowledge

8. The DHCP server confirms the client can use the requested address. Which step occurred?

   A. Request  
   B. Acknowledge  
   C. Discover  
   D. Offer
